# 模擬店どこ？（紅華祭2026）

「〇〇ってどこ？」と聞かれたときに、店名・団体名・メニューから模擬店のエリアを引くための委員会内向け検索ページ。

- 表記ゆれ（全角/半角、ひらがな/カタカナ、記号・空白）は無視して検索
- スペース区切りで AND 検索、`d 焼きそば` のように1文字でエリア指定も可
- 未入力時はエリアごとの一覧
- `?q=チュロス` / `?area=E` のURLでそのまま共有できる

## データの更新

`shops.js` だけ触ればOK。

- **何棟付近か**：`AREAS` の各エリアの `near` に書く（全店舗に反映）
- **店舗の追加・修正**：`SHOPS` に1行追加。`kw` は画面に出ない検索用の別名・ジャンル
