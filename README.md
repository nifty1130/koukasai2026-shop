# 模擬店どこ？（紅華祭2026）

「〇〇ってどこ？」と聞かれたときに、店名・団体名・メニューから場所（エリア・何棟付近・出店番号）を引くための委員会内向け検索ページ。

- 模擬店（B〜Eエリア）42店に加えて、キッチンカー（Aエリア）とコンソーシアム（F・Gエリア）も収録
- 表記ゆれ（全角/半角、ひらがな/カタカナ、記号・空白）は無視して検索
- スペース区切りで AND 検索。`d 焼きそば` のように1文字でエリア指定、`D07` / `d-7` で出店番号を直接引ける
- 未入力時はエリアごとの一覧
- `?q=チュロス` / `?area=E` のURLでそのまま共有できる

## データの更新

`shops.js` だけ触ればOK。

- **何棟付近か**：`AREAS` の各エリアの `near`
- **どちらの棟側か**：`AREAS` の `zones`（出店番号の範囲 → ラベル）
- **店舗の追加・修正**：`SHOPS` に1行追加。`kw` は画面に出ない検索用の別名・ジャンル
